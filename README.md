A six-panel editorial illustration following the supplied November 21 news brief:
Mercury exploration, climate negotiations, Bahrain, Mexico, Peru, and Baltic shipping.
The ticker covers Bangladesh garment factories and Japan–Saudi oil storage.

Artwork is generated fresh in this authoring session using the built-in image generator.
The supplied news claims are editorial inputs, not independently verified reporting.

## Run

Use Node.js 22 with TypeScript support enabled, or a newer compatible Node.js:

```sh
MAKEFUN_OUTPUT_DIR=out node --experimental-strip-types main.ts
```

The dependency-free entrypoint writes the bundled artwork to `entry.png` in the
output directory (default `/output`). It makes no network calls and preserves
the image bytes deterministically. The repository uses the MIT license.
